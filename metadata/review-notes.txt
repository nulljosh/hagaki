Hagaki is a native SwiftUI app (iOS and macOS) that sorts an inbox into seven smart folders. No account is needed to try it: open the app and tap "Try the demo inbox". It loads sample mail, lists each message under its folder (Receipts, Travel, Dev, Newsletters, Social, Promotions, Junk), and "File everything" in the top bar files them. Mail from a person with no bulk signals stays in the inbox. The demo uses sample mail only and touches no real mailbox.

With a real account, "File everything" creates labels (Gmail) or folders (iCloud Mail) named Hagaki/<folder> and moves the messages there. Nothing is deleted. Delete is a separate swipe action, and in Gmail it goes to Trash. Swipe also offers File, Archive and Unsubscribe.

Real sign-in: "Continue with Gmail" uses Google sign-in in the system browser (PKCE). "Continue with iCloud Mail" uses an app-specific password. The session token is kept in the Keychain. The app reads or changes mail only when the user taps.

This build responds to the earlier 4.3(a) feedback. The previous build wrapped a web page. This one is fully native: native sign-in, a native inbox list with sections and swipe actions, a Keychain session, and smart folders. The app was renamed from Siftbox to Hagaki. The bundle ID is unchanged.
